# Roll the Dice

Autore: Riccardo Passeri  
Creato con: Android Studio  
Versione Android supportata: API 35 e superiori

## Descrizione

Roll the Dice è un' app Android che ti permette di lanciare un dado virtuale e visualizzarne il risultato.  

### Come funziona

1. **Schermata iniziale**  
   Appena apri l'app, trovi un pulsante chiamato **"Lancia"**. Premendolo, passi alla schermata successiva dove avviene il lancio del dado.

2. **Schermata del dado**  
   Qui viene generato un numero casuale da 1 a 6, che rappresenta il lancio del dado.  
   Sullo schermo viene mostrata l'immagine del dado corrispondente al numero uscito.  
   In questa schermata trovi anche un secondo pulsante, che ti permette di proseguire.

3. **Schermata finale**  
   Nell'ultima schermata l'app ti mostra il risultato del lancio:
    - Se il numero è 4, 5 o 6, hai **vinto**.
    - Se il numero è 1, 2 o 3, hai **perso**.

## Obiettivo del gioco

L'obiettivo è semplice: lancia il dado e spera in un numero alto. Se ottieni almeno 4, vinci!

## Caratteristiche principali

- Interfaccia semplice
- Funzionamento con passaggi guidati.
- Grafica con immagini del dado reali.
- Supporto per le versioni Android più recenti.

## Requisiti

- Dispositivo Android con API 35 o superiore.
- Connessione Internet non necessaria: l’app funziona completamente offline.
